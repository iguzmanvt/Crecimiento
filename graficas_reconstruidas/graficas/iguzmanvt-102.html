Evolución relativa del gasto en I+D

Reconstrucción docente. Índice del gasto de I+D con base 2000 = 100 en cada uno de seis países. Permite comparar la evolución relativa del gasto; no permite comparar niveles monetarios absolutos entre países.

Periodo: 1981–2022; cobertura desigual por país. Unidades: Índice sin unidades, base propia de cada país en 2000 = 100. Se conservan las unidades originales sólo en los archivos de entrada, sin atribuir moneda, PPA ni base de precios..

Edición: StudyGuide archivado en 3a8c79f20022ef7b985b392d73921839a4317883; se usan las coordenadas existentes, no una nueva versión de PWT/OECD..

Reconstrucción docente · datos y fuentes en la vista completa.

Puede consultar valores, ampliar el gráfico y ocultar series desde la leyenda.

Datos CSV · Datos y animación JSON · Imagen SVG · Imagen PNG

Método: y = 100 × OBS_VALUE_t / OBS_VALUE_2000, por país. El año 2000 está presente y tiene valor positivo en las seis series archivadas.

Alcance: Reconstrucción docente nueva; la correspondencia con la apariencia o datos del ID histórico no está autenticada.; Se preserva la edición archivada; no se incorporan observaciones nuevas.; La normalización elimina la escala de cada serie y no permite comparar tamaños monetarios absolutos entre países.; No se acreditan moneda, multiplicador, PPA ni base de precios en los datos originales; tampoco se certifica la comparabilidad metodológica a lo largo del tiempo. No se interpretan a partir de PRICE_BASE=Q.
