# Materiales actualizados de Crecimiento

Notas y presentaciones de seis módulos con las 40 reconstrucciones incorporadas. Desde una copia completa del repositorio, abrir `index.html` en esta carpeta o elegir un material en la tabla. Conservar la carpeta `graficas_reconstruidas` de la raíz y los recursos que acompañan cada HTML. GitHub muestra el código HTML; las imágenes de las gráficas se pueden consultar directamente desde el [catálogo de reconstrucciones](../RECONSTRUCCION_GRAFICAS.md).

Las gráficas reconstruidas y sus descargas funcionan sin conexión. Las referencias externas de la clase y MathJax conservan sus dependencias de red; no se presentan como verificadas offline. Las fuentes Rmd son editables; para volver a generarlas usar `scripts/renderizar_modulos.R` según [las instrucciones](../REPRODUCCION_MODULOS.md).

Se conservan las imágenes y HTML históricos. Estos materiales aplican los ajustes de parámetros, unidades y explicaciones documentados en el [informe de reconstrucción](../RECONSTRUCCION_GRAFICAS.md).
